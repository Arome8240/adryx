## Design System Features Applied

### Colors
- Primary: #f97316 (Adryx orange)
- Secondary colors: purple, cyan, green, red
- Text hierarchy: primary, secondary, tertiary
- Border colors with subtle opacity

### Typography
- Inter font (300-800 weights)
- Heading classes: heading-1 through heading-4
- Body classes: body, body-sm
- Label classes: label-sm, label-xs

### Components
- Cards: card, card-lg, card-linear
- Buttons: btn-primary, btn-secondary
- Badges: badge, badge-primary
- Inputs: input, input-sm

### Animations
- Fast transitions: 100-200ms
- Smooth easing: easeOut, easeInOut
- Subtle hover effects
- Minimal motion design

## Key Changes from Previous Design

1. Removed heavy gradients and glows
2. Simplified color palette
3. Faster, more subtle animations
4. Cleaner typography hierarchy
5. More consistent spacing
6. Better accessibility with semantic classes
