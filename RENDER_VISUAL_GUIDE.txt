┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: PREPARE (5 minutes)                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Run preparation script:
     $ ./scripts/render-deploy.sh
     
  2. Push code to Git:
     $ git push origin main
     
  3. Create MongoDB Atlas account:
     → https://www.mongodb.com/cloud/atlas
     → Create free M0 cluster
     → Get connection string

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: DEPLOY BACKEND (5 minutes)                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Go to Render Dashboard:
     → https://dashboard.render.com
     
  2. Click "New +" → "Web Service"
  
  3. Configure:
     Name:           adryx-backend
     Root Directory: apps/backend
     Runtime:        Docker
     Plan:           Free (or Starter)
     
  4. Add Environment Variables:
     ┌─────────────────────────────────────────────────────────────┐
     │ NODE_ENV=production                                         │
     │ PORT=3001                                                   │
     │ MONGODB_URI=mongodb+srv://...                              │
     │ JWT_SECRET=<generated-secret>                              │
     │ SOLANA_NETWORK=devnet                                      │
     │ SOLANA_RPC_URL=https://api.devnet.solana.com              │
     │ SOLANA_PROGRAM_ID=Fg6PaFpoGXkYsidMpWTK6W2BeZ7FEfcYkg...   │
     │ CORS_ORIGIN=https://adryx-frontend.onrender.com           │
     └─────────────────────────────────────────────────────────────┘
     
  5. Click "Create Web Service"

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: DEPLOY FRONTEND (5 minutes)                                          │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Click "New +" → "Web Service"
  
  2. Configure:
     Name:           adryx-frontend
     Root Directory: apps/frontend
     Runtime:        Docker
     Plan:           Free (or Starter)
     
  3. Add Environment Variables:
     ┌─────────────────────────────────────────────────────────────┐
     │ NODE_ENV=production                                         │
     │ NEXT_PUBLIC_API_URL=https://adryx-backend.onrender.com/... │
     │ NEXT_PUBLIC_SOLANA_NETWORK=devnet                          │
     │ NEXT_PUBLIC_SOLANA_RPC_URL=https://api.devnet.solana.com  │
     │ NEXT_PUBLIC_SOLANA_PROGRAM_ID=Fg6PaFpoGXkYsidMpWTK6W...   │
     └─────────────────────────────────────────────────────────────┘
     
  4. Click "Create Web Service"

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: VERIFY (2 minutes)                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Test Backend:
     $ curl https://adryx-backend.onrender.com/api/v1/solana/info
     
     Expected: {"wallet":"...","programId":"..."}
     
  2. Test Frontend:
     → Open https://adryx-frontend.onrender.com
     → Should see homepage
     → No console errors

┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                               │
└──────────────────────────────────────────────────────────────────────────────┘

  ❌ Backend won't start
     → Check MongoDB connection string
     → Verify all environment variables
     → Check logs in Render dashboard
     
  ❌ Frontend can't connect
     → Verify NEXT_PUBLIC_API_URL
     → Check CORS_ORIGIN in backend
     → Ensure both services running
     
  ❌ CORS errors
     → Update CORS_ORIGIN with exact frontend URL
     → Include https://
     → No trailing slash
     → Redeploy backend
